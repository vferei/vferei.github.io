# Сайт-визитка

## Деплой на GitHub Pages

1. Создай репозиторий `username.github.io`
2. Залей эти файлы в ветку `main`
3. В Settings → Pages выбери ветку `main` и папку `/ (root)`
4. Готово — сайт будет доступен на `https://username.github.io`

Либо используй любой репозиторий — Pages включится на `https://username.github.io/repo-name`.

Замени в `index.html`:
- имя и фамилию
- ссылки (GitHub, Telegram, Email)
- аватар (можно свой или удалить `img`)

## Локальный запуск

```bash
open index.html
```
